# 画面情報

Codex InfoのLinux / Windows画面は、Linux / WSL上の常駐serviceが公開する同じsnapshotを表示します。Main、Graph、Threadsは別々に再計算せず、strict validation済みの単一`GET /v1/details`応答を表示データの取得元として使います。

## 画面構成

登録するtop-level surfaceは次の6つです。各child Windowは1つだけ開き、HelpはMain内に表示するため7番目のWindowではありません。

| surface | 主な役割 | Window |
| --- | --- | --- |
| Main | 接続状態、利用枠、リセット、モデル別使用量、各画面への入口 | 900×480固定 |
| Setup | 初回の接続、API readiness、認証、完了までの案内 | 900×480固定 |
| Settings | 非秘密の接続selector、接続復旧、保存・取消 | 900×480固定 |
| Graph | 期間、metric、系列、履歴plot、現在値 | 初期940×640、最小700×480、resize可能 |
| Threads | 実行中thread、親子関係、context使用率 | 900×480固定 |
| Legal | GPLと第三者素材の通知 | 900×480固定 |
| Main内Help | SSH、WSL、API、認証、更新、uninstall、障害時の確認 | 独立Windowなし |

全Windowは画面内タイトルと移動・最小化・閉じる操作を持ちます。native resize、最大化、復元を提供するのはGraphだけです。

## 起動直後

Mainは製品versionをヘッダーに1回だけ表示します。health readinessの後、最初の完全な`/v1/details` generationが揃うまでは内容を部分表示せず、固定レイアウト上にspinnerを表示します。

初回取得に失敗した場合はspinnerを解除し、失敗状態と再試行手段を表示します。`GET /v1/health`の成功はservice readinessとversionを示すだけで、認証済み・最新取得成功・data readyを意味しません。

## Mainの読み方

Mainでは次の順に確認します。

1. 接続・認証・取得失敗の状態
2. 週次または月間の利用枠残量とリセットまでの時間
3. SOL / TERRA / LUNAの入力、cache入力、出力tokenと予想ドル額
4. Graph、Threads、Settings、Legal、Helpへの入口

Setup、未認証、通常、警告、取得失敗は別の状態です。取得失敗を未認証や正常なemptyへ読み替えません。定期更新中または通信失敗時は、最後の完全なモデル・履歴・thread表示を保持し、失敗状態を別に示します。明示的なlogoutまたは認証主体の変更以外で、確定済み表示を空や0へ戻しません。

残量とモデル使用量は別の観測値です。残量が観測できない区間をtokenや料金から逆算しません。

## Graph

Graphでは期間と「ドル／トークン」を切り替え、残量、SOL、TERRA、LUNAの系列を個別に表示・非表示にできます。初期状態は全系列表示です。

履歴はSQLiteへ過去3暦月分保持し、1回の表示は選択した最長1暦月分に限定します。未使用区間、遅れて届いた残量、未観測区間を区別し、料金から残量を推測しません。右端の現在値は系列色のleaderで終端へ結びます。

## Threads

Threadsは最新の実行中threadを表示します。UIは同じ`/v1/details` snapshotで受理した`total_tokens`、`context_usage_tokens`、`context_window_tokens`を使い、contextの使用状況と累積tokenを表示します。App Server内部値や別の取得結果から再計算・補完しません。

表示順は親を先にしたdepth-firstかつsubtree-contiguousで、role、depth、orphanをtree guideで区別します。6件までは同じviewportに表示し、7件目以降だけ一覧内を縦scrollできます。

## SetupとSettings

Windowsの初回Setupは、接続準備、listener、`GET /v1/health`、`GET /v1/details`、必要な認証確認の順に進みます。WSLまたはOpenSSH configのliteral `Host` aliasを選び、password、token、private key、展開済みhost/user/pathは保存しません。

Settingsでは保存済みの非秘密selectorを変更または復旧します。保存失敗や設定破損をWelcome画面の繰返しへ変換せず、Mainのdisconnected状態とSettingsの復旧導線を示します。

## LegalとHelp

LegalはGPLの無保証条項と第三者素材の通知を主画面から分離して表示します。HelpはMain内で、SSH、WSL、API、認証、更新、uninstall、障害時に確認する情報を案内します。

## 言語と時刻

catalogは`ja`、`en`、`zh-Hans`、`ko`、`es`、`fr`、`de`、`pt`、`it`、`ru`の10件です。未対応、不正、`C`、`POSIX`は英語へfallbackします。localeとtimezoneは起動時に確定し、絶対時刻はtimezoneとUTC offset、残り時間はUTC差分から表示します。platformごとの実装・検証状態は[多言語化仕様](https://github.com/salty919/codex_info_v2/blob/main/docs/LOCALIZATION.md)を参照してください。

## 既存PNGについて

repositoryの`wiki/*.png`はLinux / X表示の参考snapshotで、Setup、Settings、Windows表示を含みません。そのため現在の6 surface構成、Windows表示、最新revisionの受入証拠としては扱いません。現在の画面を確認するときは、対象Releaseを実環境で起動し、表示versionとserviceの`product_version`が一致していることを確認してください。
